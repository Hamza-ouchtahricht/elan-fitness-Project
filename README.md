🏋️ Elan Fitness – Bilan de la semaine

📌 Introduction

Durant cette semaine, j’ai travaillé sur le projet Elan Fitness. Ce projet m’a permis de mettre en pratique les connaissances acquises en classe et de découvrir de nouvelles notions dans le domaine du développement web.

📚 Ce que j’ai appris
1. HTML

Au début du projet, nous avons utilisé du code HTML comme base pour modifier les pages Accueil,À propos,Programmes

Nous avons organisé le code afin que chaque bouton permette d’accéder à la page correspondante.

J’ai appris à comprendre le rôle des différentes balises HTML, notamment :
par exemple:
a : pour créer des liens entre les pages.
h1 a h6 : pour organiser les titres et les sous-titres.
Les balises HTML essentielles pour structurer une page web.

J’ai ensuite appliqué ces connaissances dans notre projet.

2. CSS

J’ai mis en pratique les notions de CSS apprises en classe pour améliorer la présentation du site, organiser les éléments et rendre les pages plus agréables visuellement.

3. SEO et SEA

Grâce à une présentation en classe, j’ai découvert :

SEO (Search Engine Optimization) : l’optimisation du référencement naturel d’un site web.
SEA (Search Engine Advertising) : la publicité payante sur les moteurs de recherche.

J’ai compris leur importance pour améliorer la visibilité d’un site web.

4. UI et UX Design

La présentation sur l’UI et l’UX m’a permis de comprendre l’importance du design d’interface et de l’expérience utilisateur.

J’ai appris qu’un site web doit être esthétique, clair et facile à utiliser.

5. Responsive Design

Aujourd’hui, j’ai découvert les bases du Responsive Design grâce à une présentation en classe.

Même si je ne maîtrise pas encore très bien cette notion, j’ai commencé à comprendre son importance pour adapter un site web aux différents écrans : ordinateurs, tablettes et smartphones.

💻 Mise en pratique

Pendant ce projet, j’ai essayé d’appliquer toutes les connaissances que j’ai acquises en HTML et en CSS.

J’ai également enrichi mes connaissances grâce aux présentations sur le SEO, le SEA, l’UI/UX Design et le Responsive Design.

🎯 Conclusion

Cette semaine a été une expérience enrichissante qui m’a permis de découvrir de nouvelles notions, de pratiquer le développement web et d’améliorer progressivement mes compétences.

Je dois encore approfondir certaines notions, notamment le Responsive Design, afin de mieux les maîtriser.

Merci pour cette expérience ! 🚀
